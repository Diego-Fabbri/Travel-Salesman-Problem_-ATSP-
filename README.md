# Asymmetric Traveling Salesman Problem (ATSP)

A **Mixed Integer Linear Programming (MILP)** model in **Java** for the **Asymmetric Traveling Salesman Problem**, built with the **IBM ILOG CPLEX 12.5** optimization engine via the CPLEX Java API.

## Overview

The Asymmetric Traveling Salesman Problem (ATSP) is a classic combinatorial optimization problem in Operations Research. A traveler starts from a depot, visits a set of customer nodes exactly once, and returns to the depot, minimizing the total travel cost. The problem is called **asymmetric** because the cost of traveling from node $i$ to node $j$ may differ from the cost of traveling from $j$ to $i$: $c_{ij} \neq c_{ji}$.

Subtour elimination — preventing the solution from decomposing into disconnected loops — is handled through the **Miller-Tucker-Zemlin (MTZ)** formulation, which introduces a set of auxiliary ordering variables $u_i$.

## Mathematical Formulation

### Sets

- $V^0 = U \cup \{0\}$ = complete set of nodes
- $U$ = set of customer nodes
- $0$ = depot node
- $n = |V^0|$ = total number of nodes
- $A^0 = \{(i,j) : i \neq j;\ i, j \in V^0\}$ = set of directed arcs

### Parameters

- $c_{ij}$ = cost of traveling from node $i$ to node $j$; $\forall\, (i,j) \in A^0$

### Variables

- $u_i$ = auxiliary ordering variable for node $i$ (MTZ subtour elimination); $\forall\, i \in U$
- $x_{ij}$ = binary routing variable:

$$
x_{ij} = \begin{cases} 1 & \text{if the route goes from node } i \text{ to node } j \\ 0 & \text{otherwise} \end{cases}
$$

### Objective Function

**(1)** — Minimize total travel cost

$$
\displaystyle \min \sum_{i \in V^0} \sum_{\substack{j \in V^0 \\ j \neq i}} c_{ij} \cdot x_{ij}
$$

### Constraints

**(2)** — Each node is entered exactly once

$$
\displaystyle \sum_{\substack{i \in U \\ i \neq j}} x_{ij} = 1 \qquad \forall\, j \in V^0
$$

**(3)** — Each node is left exactly once

$$
\displaystyle \sum_{\substack{j \in U \\ i \neq j}} x_{ij} = 1 \qquad \forall\, i \in V^0
$$

**(4)** — MTZ subtour elimination constraints

$$
u_i - u_j + n \cdot x_{ij} \le n - 1 \qquad \forall\, i \in U,\ j \in U,\ i \neq j
$$

**(5)** — Binary routing variables

$$
x_{ij} \in \{0, 1\} \qquad \forall\, (i,j) \in A^0
$$

**(6)** — Non-negative auxiliary variables

$$
u_i \ge 0 \qquad \forall\, i \in U
$$

> **Note on asymmetry:** Unlike the symmetric TSP, the cost matrix here is directed: $c_{ij} \neq c_{ji}$ in general. This means the outgoing and incoming arc costs between any two nodes can differ, which is common in real-world applications such as road networks with one-way streets or varying traffic conditions. Self-loops are excluded from the model.

A copy of this formulation is also available as a standalone PDF in this repository.

## Example Instance

The program solves a hardcoded **6-node** ATSP instance with an asymmetric cost matrix. The included `ATSP_Exercise.log` records the full CPLEX solution process, with an **optimal tour cost of 90.4** following the route:

$$
0 \to 5 \to 2 \to 4 \to 1 \to 3 \to 0
$$

CPLEX solved the instance in **0.02 seconds** using branch-and-cut with 4 parallel threads.

## Requirements

- **Java** 13 or later
- **Apache Maven** 3.x
- **IBM ILOG CPLEX** 12.5 — must be installed separately and added to the local Maven repository as `External_Libraries:CPLEX:12.5`
- **JUNG** 1.7.6 — Java Universal Network/Graph Framework, added to the local Maven repository as `External_Libraries:jung:1.7.6`

> CPLEX is a commercial solver. An academic license is available free of charge through the [IBM Academic Initiative](https://www.ibm.com/academic).

## Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/Diego-Fabbri/Travel-Salesman-Problem_-ATSP-.git
   cd Travel-Salesman-Problem_-ATSP-
   ```

2. Install the CPLEX JAR into your local Maven repository:
   ```bash
   mvn install:install-file \
     -Dfile=<path-to-cplex.jar> \
     -DgroupId=External_Libraries \
     -DartifactId=CPLEX \
     -Dversion=12.5 \
     -Dpackaging=jar
   ```

3. Install the JUNG JAR into your local Maven repository:
   ```bash
   mvn install:install-file \
     -Dfile=<path-to-jung.jar> \
     -DgroupId=External_Libraries \
     -DartifactId=jung \
     -Dversion=1.7.6 \
     -Dpackaging=jar
   ```

4. Build and run with Maven:
   ```bash
   mvn clean package
   mvn exec:java
   ```

   Or open the project directly in **NetBeans IDE** and use the pre-configured run action (`nbactions.xml`).

## Output

When executed, the program:
- Builds the MILP model programmatically using the CPLEX Java API
- Solves it and prints the solver status and optimal tour cost
- Exports the model in LP format (`ATSP_Exercise.lp`)
- Writes the full CPLEX solver log to `ATSP_Exercise.log`, including:
  - Branch-and-cut progress and gap evolution
  - Optimal objective value (minimum tour cost)
  - All active arcs $x[i][j] = 1$ defining the optimal route
